##Кейс-задача № 3

Спроектируйте базу данных «Туризм» (перечень предоставляемых услуг, заказ туров и др.). 
При проектировании базы данных необходимо создать 4-5 таблиц предметной области: 
3-4 таблицы-справочника и 1 таблицу переменной информации. 
Для всех таблиц создать первичные ключи. 
Построить связи между таблицами при помощи внешних ключей: 
атрибуты таблицы переменной информации должны ссылаться 
на ключевые атрибуты таблиц справочников. 


## Структура базы данных

База спроектированна соогласно условию и состоит из 5 таблиц:
* **4 таблицы-справочника:**
  * `clients` — клиенты;
  * `tours` — туры (направления);
  * `services` — дополнительные услуги;
  * `employees` — сотрудники.
* **1 таблица переменной информации:**
  * `orders` — заказы (факты покупок).
